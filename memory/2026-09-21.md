## 星购商城登录页面（starshop-login.html）
- 需求：星空主题的购物软件登录界面，字体颜色也要包含星空主题元素
- 产出：`C:\Users\Administrator\WorkBuddy\2026-09-21-08-39-05\starshop-login.html`（单文件 HTML，无外部依赖）

### 设计要点
- **星空背景**：深蓝紫渐变夜空 + Canvas 粒子星海 + 渐盈/发光月亮 + 多层星云 + 旋转银河带
- **动态效果**（用户二次要求"背景要会动"后增强）：
  - 星星分 3 层视差横向漂移（远星慢/暗/小，近星快/亮/大），移出边界后从右侧循环回来
  - 星星按各自频率呼吸闪烁；两组星云做 24s / 32s 错位漂浮缩放；银河 conic-gradient 120s 缓慢旋转
  - 26 颗亮星之间近邻连线（<约 205px）形成缓慢重组的"星座网"
  - 随机流星：渐变金色拖尾 + 发光头部
- **星空字体配色**（贯穿全站）：
  - 主渐变 青 #7dd3fc → 紫 #a78bfa → 粉 #f9a8d4 → 金 #fde68a
  - 使用 `background: linear-gradient + background-clip: text + color: transparent` 实现渐变文字
  - 配合 drop-shadow / text-shadow 星光晕；slogan 用流动渐变动画
- **布局**：登录卡片（玻璃拟态 backdrop-filter）+ 下方网站用途介绍区；页面可滚动但背景 fixed，沉浸感保留
- **用途区**：4 个功能卡（精选好物 / 限时秒杀 / 会员权益 / 极速配送）+ 关于本站说明 + 服务标签

### 技术备忘

- 表单校验 + toast 提示 + 密码明文切换 + 返回顶部按钮
- 响应式断点：860px 用途卡 2 列，480px 单列
